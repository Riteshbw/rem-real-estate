# REM Real Estate — Contemporary Architectural Property Platform

A luxury, verified real estate discovery and investment platform engineered for direct developer disintermediation, verified RERA documentation, and accessible commercial micro-equity co-ownership in Bengaluru.

## Live Staging
🔗 **Live Site:** [https://riteshbw.github.io/rem-real-estate/](https://riteshbw.github.io/rem-real-estate/)

## Key Architectural & Functional Highlights
- **100% Direct-to-Developer (Zero Brokerage):** Integrated direct telephone dialers and WhatsApp bridges bypassing middleman commissions.
- **Verified Property Intelligence:** 13 verified asset dossiers spanning luxury residential apartments, gated villa plots, and commercial tech hubs with 100% statutory RERA clearances and usable carpet area efficiency scoring.
- **Algorithmic Fractional Co-Ownership:** Micro-equity syndicate simulator partitioning high-value commercial tech parks (Deloitte / AWS IT floors) into standardized 10-share co-investment pools delivering 9.6% net monthly rental yields.
- **Architectural Lighting Split-Slider:** Interactive Day vs. Twilight architectural lighting viewer.
- **Client-Side Specification Dossier:** Instant browser-based brochure compilation and export (`Blob`).
- **Zero-Dependency Architecture:** Lightning-fast static single-page application with responsive Tailwind design and custom kinetic animations.

Double-click `start-website.bat` or open `index.html` in any modern web browser.
